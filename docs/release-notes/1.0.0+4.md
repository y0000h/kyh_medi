# 1.0.0+4 (versionCode 4) — 릴리스 노트

> 1.0.0+3 이후 누적 변경. 핵심은 **전체 UI 라이트 리디자인** + **배포 준비 정리**.
> Play Console / App Store "이 버전의 새로운 기능"에 짧은 버전을 그대로 붙여넣기.

---

## 짧은 버전 (스토어 "새로운 기능" 칸 — 500자 한도)

```
- 전체 화면을 밝고 깔끔한 새 디자인으로 단장(부모=블루, 자녀=연두)
- 홈: 주간 달력 + 복용 진행률 + 시간대별 약 카드 + '먹었어요' 도장
- 약 등록을 3단계 마법사로(색상·사진·복용기간·시간·알림)
- 복용 일정/이력 화면 카드 정리, 약 색이 카드에 반영
- 자녀 모드 화면 톤 통일, 부모 '자녀와 연결' 화면 새 단장
- 앱 이름 'KYH 약 알림'으로 통일, 자잘한 안정성 개선
```

## 긴 버전 (변경 요약)

### 디자인 — 전면 라이트 리디자인
- 다크(에스프레소) → **라이트 프리미엄**으로 피벗. 부모=세련된 블루 `#3D7BF5`,
  자녀=연두 `#5DAE4E`. 네이버 나눔스퀘어.
- **홈**: 주간 캘린더 스트립 + 원형 진행률 링 + 시간대별 약 카드 + '먹었어요' 버튼 + 완료 도장.
- **약 등록 3단계 마법사**: 알약 색상 선택 / 사진(카메라·갤러리) / 식사시점 세그먼트 /
  복용 기간(휠 날짜 피커) / 복용 시간 + 알림 토글.
- **복용 일정·약 관리·이력**: 화이트 카드 톤 정리. 약 색(colorHex)이 아바타·일정 점에 반영.
- **이력**: 캘린더 카드 + 완료/미복용/일부 범례 + 날짜별 기록 카드.
- **시간 슬롯 폼 / 자녀와 연결**: 구식 위젯 제거하고 마법사 톤으로 재구성.
- **자녀 모드**: 홈 부모 카드·로그인 버튼 톤 통일(부모 상세 기준).
- 설정·온보딩 모던 카드, 도움 챗봇 추천 질문 칩.

### 인프라 / 안정성
- Supabase 무료 플랜 일시정지 예방 keep-alive cron(3일마다 REST 핑).
- 챗봇·이메일 OTP 무응답 원인(프로젝트 일시정지) 진단·복구 + 친절한 한국어 에러 안내.
- 자녀 로그인/홈 앱바·뒤로가기 흐름 픽스.

### 배포 준비 (1.0.0+4 동안)
- 앱 표시 이름 **iOS·Android "KYH 약 알림"** 통일(이전 iOS만 영문 "Kyh Medi").
- 광고 단위 ID **릴리스/디버그 분기** — 릴리스에서 실 ID 미설정 시 배너 미표시(테스트 광고
  실수 출시 방지). 디버그는 테스트 ID 유지.
- 개인정보처리방침 **공개 페이지화**(`site/index.html` + GitHub Pages 워크플로), 정본 일원화.
- iOS 푸시 `UIBackgroundModes: remote-notification` 추가 + 셋업 가이드.
- Android 업로드 키스토어 재생성·서명 빌드 검증.
- 릴리스 빌드 스모크 통과(AAB 64.5MB / iOS Runner.app 38.6MB).

### 검증
- `flutter analyze` 에러 0, 테스트 16개 통과.
- iOS 시뮬레이터 end-to-end(약 등록 → 슬롯 → 이력 → 자녀 로그인 → 자녀와 연결 코드 발급).
