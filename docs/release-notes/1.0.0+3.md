## 긴 버전 (사용자 직접 검증 가이드 — 폰 install 후 체크리스트)

### 새 기능 / 변경

**부모 모드**
- 홈 카드: 슬롯별 시간 + 상태 뱃지(`복용 완료` / `미복용` / `복용 전`) 정렬 수정.
- 설정 진입 흐름 단순화.
- 모드 변경: 다이얼로그 → 변경 → 모드 선택 화면 복귀 흐름 정상 작동.
- 도움 탭: Gemini 챗봇 통합. 약 복용 관련 한국어 질문 응답.

**자녀 모드**
- 인증: 이메일/비번 → 이메일 OTP(매직 링크) 전환.
- OTP 길이 가변(6/8자리) 대응.
- 면책 문구 한 번만 표시.

**디자인**
- 새 알약 아이콘 v3: 페치 컬러 + 캡슐 X자 + 작은 알약 + 스파클.
- 토큰 구조: 단일 파일 → `core/theme/tokens/` 폴더 분할 (colors / spacing /
  radius / shadows / sizes / typography). import 경로 동일.
- `AppSemanticColors` ThemeExtension: 부모/자녀 팔레트 자동 분기.
- 새 primitive: `SectionCard` (Card+InkWell+Padding 보일러플레이트 캡슐화).
- `SeniorButton`: `color:` 파라미터 → `variant: primary/secondary/success/destructive`.

**코드 품질**
- `flutter analyze` clean (No issues found).
- async gap 경고 4건 정리(initState microtask 가드 + provider ref pre-capture).
- 임시 디버그 캡처(`/_*.png`, `docs/screenshots/_*.png`)는 `.gitignore`로 자동 무시.

### 검증 우선 체크리스트

폰(R5CX70BV5YT, Galaxy Z Flip 6)에 install 후 순서:

1. **자녀 로그인** → 이메일로 OTP 코드 도착 → 6/8자리 입력 → 진입.
2. **자녀 진입 후** → 면책 문구가 **한 번만** 나오는지.
3. **부모 모드 → 설정 → 모드 변경** → 다이얼로그 → 변경 → 모드 선택 화면.
4. **부모 모드 → 도움 탭** → 챗봇에 "타이레놀 식후 복용 OK?" 같이 입력 → 응답.
5. **새 알약 아이콘 v3** 마음에 드는지 (홈 화면 launcher icon).
6. **광고 제거 결제 / 구매 복원** (settings) 두 버튼 visual OK.

### 회귀 의심 시 — 단일 단계 rollback

| 변경 영역 | rollback 명령 |
|---|---|

| async cleanup | `git revert 96e1414` |

| 자녀 인증 OTP | `git revert 391fa51` |

각 커밋은 의미 단위로 분리되어 있어 단일 revert로 격리 가능.
