# KYH 약 알림 개인정보처리방침

최종 갱신: 2026-05-02 (출시일에 다시 갱신 예정)

본 개인정보처리방침은 모바일 앱 **KYH 약 알림**(이하 "본 앱")이 사용자의 개인정보를 어떻게 처리하는지 설명합니다.

---

## 1. 수집하는 개인정보

### 부모 모드 (자녀와 연결을 사용하지 않는 경우)

**어떠한 개인정보도 수집하지 않습니다.** 모든 데이터(약 정보, 복용 이력, 사진, 메모)는 **사용자의 기기 안에만** 저장되며, 본 앱 외부 서버나 제3자에게 전송되지 않습니다.

### 자녀와 연결 기능을 사용하는 경우

부모님의 복약 상태를 자녀가 원격으로 확인할 수 있도록 다음 데이터가 Supabase 클라우드에 저장됩니다:

| 데이터 | 출처 | 용도 |
|---|---|---|
| 약 이름 (텍스트) | 부모 입력 | 자녀 화면에 표시 |
| 복용/미복용 이벤트 (날짜/시각/상태) | 부모 앱 자동 기록 | 자녀 화면 통계 + 미복용 푸시 트리거 |
| 자녀 이메일 주소 | Google 로그인 또는 이메일 가입 | 자녀 인증 |
| 자녀 표시 이름 | Google 프로필 또는 사용자 입력 | 자녀 화면 인사 |
| FCM 푸시 토큰 | Firebase 자동 발급 | 부모 미복용 시 자녀에게 푸시 발송 |

### 절대 클라우드로 전송되지 않는 정보

- **약 사진과 메모**는 부모님 기기에만 보관되며 어떠한 경우에도 클라우드 또는 자녀에게 전송되지 않습니다.
- 부모 기기의 위치, 연락처, 통화 기록 등은 수집하지 않습니다.

## 2. 권한 사용 목적

| 권한 | 사용 목적 | 모드 |
|---|---|---|
| 알림 (POST_NOTIFICATIONS) | 약 복용 시각 정시 알림 + 미복용 시 자녀에게 푸시 | 부모 + 자녀 |
| 정확한 알람 (SCHEDULE_EXACT_ALARM) | 시간 슬롯에 맞춘 정확한 시각 알림 | 부모 |
| 카메라 / 미디어 (CAMERA, READ_MEDIA_IMAGES) | 약 등록 시 사진 첨부 (선택) | 부모 |
| 부팅 시 실행 (RECEIVE_BOOT_COMPLETED) | 재부팅 후 알림 자동 재등록 | 부모 |
| 인터넷 (INTERNET) | 자녀와 연결 시 Supabase + Firebase 통신 | 부모 (페어링 후), 자녀 |
| 광고 식별자 (AD_ID) | AdMob 광고 송출 (광고 제거 결제 시 비활성) | 부모 |

---

## 3. 광고

부모 모드 일부 화면(약 목록, 복용 이력 캘린더, 설정 화면)에 한해 **Google AdMob 배너 광고**를 표시합니다.

- **자녀 모드는 광고가 없습니다.**
- 사용자는 인앱 결제(₩2,900, 평생)로 광고를 영구 제거할 수 있습니다.
- AdMob SDK에는 약 이름, 복용 이력, 사진 등 **어떠한 의료 정보도 전달되지 않습니다.**
- AdMob의 데이터 처리: <https://policies.google.com/privacy>

---

## 4. 결제

광고 제거 상품(`kyh_remove_ads_lifetime`, ₩2,900)은 **Google Play 결제 시스템**을 통해 처리됩니다. 본 앱은 사용자의 결제 정보(카드 번호 등)를 직접 수집하지 않습니다.

---

## 5. 데이터 보관 / 암호화

- Supabase 클라우드 저장은 모두 **HTTPS(TLS) 암호화** 통신.
- 데이터베이스 행 단위 접근 통제(Row Level Security): 부모는 본인 데이터, 자녀는 페어링된 부모의 데이터만 접근 가능.
- FCM 토큰은 자녀 본인 row 외에는 노출되지 않습니다.

---

## 6. 데이터 삭제 / 연결 해제

- **페어링 해제**: 부모 또는 자녀가 설정 화면에서 페어링을 해제하면 양쪽 데이터 연결이 끊어집니다 (자녀가 더 이상 부모 데이터를 볼 수 없음).
- **자녀 계정 삭제**: 자녀 계정 자체 삭제는 아래 이메일로 요청해주시면 14일 이내 처리합니다.
- **부모 로컬 데이터 삭제**: 앱 설정 → 앱 데이터 삭제 또는 앱 제거.
