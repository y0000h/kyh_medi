## B. Play Console 앱 만들기 (10분)

1. <https://play.google.com/console> 로그인
2. 좌측 상단 **앱 만들기** 클릭
3. 입력:
   - **앱 이름**: `KYH 약 알림`
   - **기본 언어**: 한국어 - ko-KR
   - **앱 또는 게임**: 앱
   - **무료 또는 유료**: 무료
   - 약관 체크박스 모두 동의
4. **앱 만들기**

→ 좌측에 새 앱이 등록되고 대시보드로 이동.

| 데이터 유형 | 수집 | 공유 | 선택사항 | 목적 |
|---|---|---|---|---|

| 이름 (Google 표시 이름) | ✅ | ❌ | ✅ | 자녀 화면 표시 |
| 사진/동영상 (약 사진) | ❌ (기기 안에만) | ❌ | — | — |

| 위치 / 연락처 / 통화 기록 | ❌ | ❌ | — | — |

**보안 관행**:

## E. AAB 업로드 + 내부 테스트 출시 (20분)

좌측 메뉴 → **테스트** → **내부 테스트** → **새 버전 만들기** 클릭.

### E-1. 앱 무결성 — Play 앱 서명

처음이라면 자동 안내 — Google이 앱 배포 키를 관리하고 본인은 업로드 키만 가지는 구조. **계속**.

### E-2. AAB 업로드

`build/app/outputs/bundle/release/app-release.aab` 드래그 앤 드롭 또는 파일 선택.

### E-3. 출시명

`v1.0.0` (또는 자동으로 `1 (1.0.0)`).

### E-4. 출시 노트

```
v1.0.0 — 첫 출시
- 어르신 약 알림 (부모 모드)
- 자녀 원격 모니터링 (페어링 + 미복용 푸시)
- 약 등록 (텍스트 + 사진, 부모 로컬만)
- 시간 슬롯별 복용 알림 (정시 + 10분 + 20분)
- 복용 이력 캘린더
- 광고 제거 인앱 결제 (₩2,900)
```

### E-5. 다음 → 검토 시작

화면 상단 **검토 시작** → 모든 항목 ✓ → **변경사항 저장하고 출시 시작**.

> 첫 출시는 Google이 기본 검토에 1~3일 소요. 내부 테스트는 보통 빠름(1시간~24시간).

## F. 테스터 등록 + 옵트인 (5분)

좌측 메뉴 → **내부 테스트** → **테스터** 탭.

1. **이메일 목록 만들기** 클릭 → 이름 `kyh-medi-internal` → 본인 + 가족 이메일 추가 → 저장
2. 다시 내부 테스트 페이지 → **옵트인 URL** 복사 → 본인 폰 브라우저에서 열기
3. "테스터가 되기" 클릭 → "Play Store에서 다운로드" 링크 → 설치 → release 빌드 검증

## H. 최종 E2E 검증 (실기기 옵트인 후)

본인 폰에서 Play Store 통해 설치된 release 빌드로 다음 모두 통과:

### 부모 모드 (13개)
- [ ] cold launch < 5초
- [ ] 모드 선택 → "부모님" → 온보딩 → 메인
- [ ] 약 등록 (텍스트만)
- [ ] 약 등록 (사진 picker 동작)
- [ ] 시간 슬롯 추가 + 정시 알림 발사
- [ ] +10분 / +20분 retry 알림 도착
- [ ] 알림 탭 → 복용 체크 화면
- [ ] 다 복용 → taken 마킹 + retry 알림 cancel
- [ ] 캘린더 — 오늘 점 색깔 정확
- [ ] 광고 배너 약 목록 / 캘린더 / 설정 하단 표시
- [ ] 광고 제거 결제 흐름 (테스트 결제 — 실제 결제 직전 취소)
- [ ] 자녀와 연결 → 6자리 코드 발급 + 카운트다운
- [ ] 페어링 목록 + 연결 해제

### 자녀 모니터링 (10개)
- [ ] Google 로그인 (release SHA-1 등록 확인)
- [ ] 또는 이메일 가입
- [ ] 부모님 추가 → 6자리 코드 redeem
- [ ] 홈에 부모 카드 표시 + 오늘 통계
- [ ] 부모 카드 탭 → 부모 상세
- [ ] 부모 폰 약 추가 → 자녀 부모 상세 Realtime 반영
- [ ] 부모 missed → 자녀 폰 푸시 도착 (FCM 셋업 완료 후)
- [ ] 자녀 모드 광고 없음 확인
- [ ] 새로고침 pull-to-refresh
- [ ] 자녀 페어링 해제 (부모 측에서) → 자녀 부모 카드 사라짐

통과 못 한 항목은 **v1.0.1 패치 백로그**로.
