# AdMob 광고 ID 발급 가이드 (처음 하는 사람용)

> KYH 약 알림에 넣을 **실제 AdMob ID 4개**를 발급받는 방법. 안드로이드/iOS는 **각각 따로** 등록한다.
> 작성 2026-06-25.

## 0. 먼저 개념 — ID가 2종류, 플랫폼마다 따로

AdMob에는 두 가지 ID가 있다. 헷갈리기 쉬우니 구분자(`~` vs `/`)로 외우면 쉽다.

| 종류 | 형식 | 예시 | 어디서 나옴 |
|---|---|---|---|
| **앱 ID** | `ca-app-pub-숫자`**`~`**`숫자` | `ca-app-pub-1234567890123456~1112223334` | 앱을 등록하면 발급 |
| **광고 단위 ID** | `ca-app-pub-숫자`**`/`**`숫자` | `ca-app-pub-1234567890123456/9998887776` | 앱 안에서 "광고 단위" 만들면 발급 |

- **`~`(물결) = 앱 ID**, **`/`(슬래시) = 광고 단위 ID**. 이 둘을 절대 바꿔 넣으면 안 된다.
- **안드로이드와 iOS는 AdMob에서 완전히 별개의 앱**으로 등록한다. 그래서 앱을 **2번** 등록하고,
  각각 광고 단위를 만든다 → 결국 필요한 값이 **4개**:

| # | 값 | 형식 | 이 프로젝트에서 들어갈 곳 |
|---|---|---|---|
| 1 | Android **앱 ID** | `~` | `android/app/src/main/AndroidManifest.xml` |
| 2 | iOS **앱 ID** | `~` | `ios/Runner/Info.plist` (`GADApplicationIdentifier`) |
| 3 | Android **배너 단위 ID** | `/` | `lib/.../ad_banner.dart` `_prodUnitIdAndroid` |
| 4 | iOS **배너 단위 ID** | `/` | `lib/.../ad_banner.dart` `_prodUnitIdIOS` |

> 이 4개를 받아서 알려주면 코드 4곳에 내가 반영한다. (현재는 전부 구글 **테스트 ID**라 릴리스에선 배너가 안 뜨게 막아둔 상태)

---

## 1. AdMob 계정 만들기 (최초 1회)

1. <https://admob.google.com> 접속 → 우측 상단 **시작하기**.
2. **구글 계정**으로 로그인 (앱 운영에 쓸 계정 — 예: y0000h2@gmail.com).
3. 국가(대한민국), 시간대, 약관 동의 → 계정 생성.
4. AdMob은 내부적으로 **구글 애드센스(AdSense)** 계정과 연결된다. 처음이면 애드센스도 같이 생성된다.
5. (수익 정산을 받으려면) **결제 정보 + 세금 정보** 입력이 나중에 필요하다. **광고 단위 생성·앱 출시까지는 없어도 되고**,
   실제 수익이 일정 금액(약 $100) 쌓여 지급받기 전에만 채우면 된다. 지금 당장은 건너뛰어도 됨.

> ⏳ 신규 AdMob 계정은 검토에 시간이 걸릴 수 있다(보통 즉시~며칠). 광고가 실제로 게재되려면 계정이 "활성" 상태여야 한다.

---

## 2. 안드로이드 앱 등록 → 앱 ID + 배너 단위 ID

1. AdMob 좌측 메뉴 → **앱** → **앱 추가**.
2. "앱이 Google Play 또는 App Store에 등록되어 있나요?"
   - 아직 미출시면 → **아니요**.
   - 플랫폼 선택: **Android**.
   - 앱 이름 입력: `KYH 약 알림` (또는 패키지명). 
   - (참고: 이 앱의 Android 패키지명 = `com.kyh.medi.kyh_medi`)
3. 등록하면 **앱 ID(`ca-app-pub-…~…`)** 가 발급된다. → **값 #1** (메모).
   - 앱 → 해당 앱 → **앱 설정**에서 언제든 다시 볼 수 있다.
4. 같은 앱 안에서 **광고 단위** 만들기:
   - 좌측 → **광고 단위** → **광고 단위 추가**.
   - 형식: **배너(Banner)** 선택. (이 앱은 하단 배너만 사용)
   - 광고 단위 이름: 예 `parent_home_banner` (자유).
   - 만들면 **광고 단위 ID(`ca-app-pub-…/…`)** 발급. → **값 #3** (메모).

---

## 3. iOS 앱 등록 → 앱 ID + 배너 단위 ID (2번과 동일, 플랫폼만 iOS)

1. **앱** → **앱 추가** → "등록되어 있나요?" **아니요** → 플랫폼 **iOS**.
2. 앱 이름 `KYH 약 알림`. (이 앱의 iOS 번들 ID = `com.kyh.medi.kyhMedi`)
3. **앱 ID(`~`)** 발급 → **값 #2**.
4. 그 앱 안에서 **광고 단위 추가 → 배너** → **단위 ID(`/`)** 발급 → **값 #4**.

> 안드로이드용 ID를 iOS에 넣거나 그 반대로 하면 광고가 안 뜨거나 정책 위반이 될 수 있다. 플랫폼을 꼭 맞출 것.

---

## 4. 받은 값 정리해서 전달

아래처럼 4개를 정리해서 주면 코드에 반영한다:

```
Android 앱 ID(~):      ca-app-pub-________~________
iOS 앱 ID(~):          ca-app-pub-________~________
Android 배너 단위(/):   ca-app-pub-________/________
iOS 배너 단위(/):       ca-app-pub-________/________
```

반영 위치(참고):
- `ios/Runner/Info.plist` → `GADApplicationIdentifier` (값 #2)
- `android/app/src/main/AndroidManifest.xml` → `com.google.android.gms.ads.APPLICATION_ID` (값 #1)
- `lib/features/parent/monetization/ad_banner.dart` → `_prodUnitIdAndroid`(#3), `_prodUnitIdIOS`(#4)

## 5. 알아둘 점 (처음이라 헷갈리는 것들)

- **테스트 광고 vs 실제 광고**: 개발 중에는 구글 **테스트 ID**를 써야 한다(자기 실제 광고를 자기가 클릭하면
  정책 위반 → 계정 정지). 이 프로젝트는 **디버그=테스트 ID 자동 / 릴리스=실 ID**로 분기돼 있어,
  실 ID를 넣어도 개발 빌드는 안전하다.
- **신규 광고 단위는 첫 몇 시간 빈 광고**가 정상이다(채워지는 데 시간 걸림). 바로 안 떠도 당황 X.
- **출시 전에도 광고 단위는 만들 수 있다**(앱 "아니요"로 등록). 단, 실제 게재·수익은 앱이 스토어에 올라가고
  AdMob에서 스토어 연결을 마친 뒤 본격화된다.
- **app-ads.txt**(선택): 광고 사기 방지용. 개발자 웹사이트 루트에 파일을 올려 AdMob에서 인증하면 좋다.
  필수는 아니지만 권장. (없어도 광고는 나온다)
- **결제/세금 정보**: 수익을 실제로 받으려면 AdMob → 지급 메뉴에서 입력. 광고를 켜는 것 자체엔 불필요.
- **광고 제거 인앱결제**: 이 앱은 ₩2,900 결제 시 광고가 사라지고, 자녀 모드엔 광고가 없다. (이미 구현됨)

---

## 6. 지금 안 해도 출시는 가능

광고 실 ID가 없어도 **광고 없이 먼저 출시**할 수 있다(릴리스 빌드는 실 ID 미설정 시 배너를 안 띄움).
나중에 AdMob 계정·ID가 준비되면 값 4개만 주면 반영 후 다음 버전에 광고가 들어간다.
