## 흐름

### 1. macOS 개발 환경 신규 구축

Homebrew만 있던 맥에 단계적으로 설치:

- **Flutter SDK 3.44.1** (`brew install --cask flutter`) / Dart 3.12.1
- **Android Studio** + **android-commandlinetools** (sdkmanager) → platform-tools / emulator / build-tools;35 / platforms 35·36 / system-image(android-35 google_apis arm64-v8a)
- 라이선스 수락, `flutter config --android-sdk` / `--jdk-dir`(Android Studio 번들 JBR)
- AVD `kyh_pixel`(Android 15) 생성 + 부팅
- `~/.zshrc`에 `ANDROID_HOME` / PATH / `JAVA_HOME` 영구 등록
- **검증**: `flutter build apk` 성공 → 에뮬레이터 설치·실행 → 모드 선택 화면 정상

### 2. iOS 플랫폼 신규 추가 + 크래시 3건 수정

`Xcode 26.5`(App Store) + **CocoaPods 1.16.2** 설치, iOS 시뮬레이터 런타임(iOS 26.5) 다운로드.
`flutter create --platforms=ios .`로 `ios/` 생성. SPM↔CocoaPods 충돌로 `flutter config --no-enable-swift-package-manager` + `Podfile platform :ios, '15.0'`.

iOS 실행 시 발견·수정한 크래시 (전부 iOS 미설정 탓, **Android 동작은 무영향**):

| 증상 | 원인 | 수정 |
|------|------|------|
| 부팅 즉시 종료 | `firebase_options.dart`가 iOS에서 `throw UnsupportedError` (main이 await) | [lib/main.dart](../../lib/main.dart) — Firebase/FCM·AdMob 초기화 try/catch |
| 흰 화면(runApp 전 멈춤) | `flutter_local_notifications`가 iOS 초기화 설정 필수 | [notification_service.dart](../../lib/core/notification/notification_service.dart) — `DarwinInitializationSettings` 추가 |
| `GADInvalidInitializationException`(네이티브) | Info.plist에 AdMob app id 없음 | [ios/Runner/Info.plist](../../ios/Runner/Info.plist) — `GADApplicationIdentifier`(테스트 ID) + 카메라/사진 권한 문구 |

추가: [ad_banner.dart](../../lib/features/parent/monetization/ad_banner.dart) 배너 테스트 단위 ID를 플랫폼별 분기(iOS 테스트 ID).

**검증**: iOS 시뮬레이터에서 모드 선택 → 부모 홈("오늘의 약")까지 정상. flutter run / 단독 실행 양쪽 안정.

### 3. Firebase iOS 구성

Firebase 콘솔(`kyh-medi`)에 iOS 앱(`com.kyh.medi.kyhMedi`) 등록 → `GoogleService-Info.plist` 다운로드.

- plist를 `ios/Runner/`에 배치 + **Xcode Runner 타깃 리소스로 등록**(CocoaPods 번들 `xcodeproj` gem 스크립트 사용)
- [firebase_options.dart](../../lib/firebase_options.dart) iOS `FirebaseOptions` 추가 (기존 throw → `return ios`)
- **검증**: iOS에서 Firebase 정상 초기화(예외 0건), 부모 홈 진입.

> FCM 실제 푸시 수신은 APNs 인증키 + Apple Developer 멤버십(유료) + 실기기 필요 → 시뮬레이터 범위 밖 (v2).

### 4. 출시 전 최종 기능 테스트 (E2E 통합 테스트)

- 기존 **단위 테스트 16개** 통과(repository·알림 스케줄러·timezone).
- 신규 **[integration_test/app_test.dart](../../integration_test/app_test.dart)** 작성:
  - **부모 모드 14단계**: 홈 빈 상태 → 약 관리 → 약 2종 등록(혈압약+메모/당뇨약) → 시간 관리 → 시간 슬롯 생성(아침 08:00, 매일, 약 2개 연결) → 오늘의 약 노출+"복용 전" → 슬롯 진입 → "복용 완료" 반영 → 이력 → 설정(자녀연결/모드변경/앱정보) → 모드변경 다이얼로그 → 약 삭제.
  - **자녀 모드 2단계**: 로그인 화면 렌더 + 잘못된 이메일 검증.
  - 상태 시드(parent/onboardingDone/adsRemoved)로 결정성 확보, NavigationBar 내부 라벨 타깃·`ensureVisible` 등 견고화.
