## ⚠️ 부분 진행 — 챗봇 응답 검증 미완

`03_helper_chat.png`는 **인사말 풍선만** 잡힘. 사용자 메시지 입력 + Gemini 응답 풍선까지 잡으려고 시도했으나 실패.

### 시도

```bash
adb input tap 469 2025         # EditText 포커스
adb input text "hi"            # 영문 — 한글은 input text가 안 먹어 영문으로 우회
adb input tap 990 2024         # send 버튼
sleep 12                        # Gemini API 대기
screencap                       # → 사용자 메시지 풍선도 안 보이고 placeholder 그대로
```

### 의심

- IME가 input 이벤트 hijack해서 EditText에 글자가 안 박힘
- 또는 input tap이 EditText 영역 밖으로 떨어졌을 가능성 (좌표는 dump 기반이라 맞아야 함)
- 다음 세션에서 `adb shell ime list -a`로 IME 확인 후 ADBKeyboard 설치 or `input keyevent` 조합 or 그냥 클립보드 paste 시도

### 재개 시 첫 명령 — 시나리오 A: emulator 살아있음

```bash
ADB="/c/Users/y00h/AppData/Local/Android/Sdk/platform-tools/adb.exe"
"$ADB" -s emulator-5554 shell getprop sys.boot_completed   # "1" 이면 살아있음

```

### 재개 시 첫 명령 — 시나리오 B: emulator 죽음 → cold boot

```powershell
# PowerShell 새 창에서
$adb = "C:\Users\y00h\AppData\Local\Android\Sdk\platform-tools\adb.exe"
& "$env:LOCALAPPDATA\Android\Sdk\emulator\emulator.exe" -avd Pixel_7 -no-snapshot-load
& $adb -s emulator-5554 wait-for-device
do { Start-Sleep 2 } until ((& $adb -s emulator-5554 shell getprop sys.boot_completed).Trim() -eq "1")
# (System UI ANR 뜨면 BACK)
& $adb -s emulator-5554 shell input keyevent KEYCODE_BACK
& $adb -s emulator-5554 shell monkey -p com.kyh.medi.kyh_medi -c android.intent.category.LAUNCHER 1
```

### 해결한 함정 (다음 세션에서 같은 실수 X)

1. **PowerShell `>` redirect는 PNG 깨뜨림** — UTF-16 인코딩으로 PNG 헤더 망가짐. 바이너리는 **bash로 redirect** (`adb exec-out screencap -p > foo.png` in Git Bash)
2. **Git Bash가 `/sdcard/...`를 Windows 경로로 자동 변환** — `MSYS_NO_PATHCONV=1` prefix 필요
3. **디스플레이 좌표 × 1.20 ≠ 정확** — 사용자가 알려주는 변환비 믿기보단 `uiautomator dump`로 정확한 bounds 추출이 안전. 첫 시도에서 (540, 1800)으로 부모 버튼 탭했지만 실제 버튼은 (540, 1513)이라 빗나감
4. **첫 부모 모드 진입 시 알림 권한 onboarding 거쳐야 함** — pm clear 후 매번 거침. 어제 RESUME에 명시 X였음
