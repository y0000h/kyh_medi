## Task 7.3 — Provider/app.dart에 sync 콜백 연결 ✅

**목적**: `MedicationsProvider`/`IntakeProvider`가 약/복용 이벤트 발생 시 자동으로 sync 호출하도록 연결.

### 변경

| 파일 | 변경 |
|---|---|
| `lib/features/parent/medication/ui/medications_provider.dart` | 생성자에 `{ParentSyncService? sync}` 파라미터 추가. `add()`/`remove()` 끝에 `_sync?.upsertMedication(m)` / `_sync?.markMedicationDeleted(id)` 호출. |
| `lib/app.dart` | `_parentApp()` 안에 `ParentSyncService` 인스턴스 + `IntakeProvider` 사전 생성 + `onMissed`/`onTaken` 콜백 연결. MultiProvider에 `Provider.value(value: sync)` + `ChangeNotifierProvider.value(value: intakeProvider)` 추가. |

### 메모

- `IntakeProvider`는 `..onMissed = ...`/`..onTaken = ...`에 클로저 직접 할당이라 hot-reload 시 listener 누수 위험 없음 (StatefulWidget의 lifecycle과 동일하게 _parentApp 호출 시점에 새로 생성됨).
- `ParentSyncService()`는 stateless라 매번 새로 만들어도 비용 없음. 그래도 인스턴스를 한 번만 만들어 4 군데(MedicationsProvider, IntakeProvider.onMissed/onTaken, Provider.value)에서 공유.
- `flutter analyze` (3 파일): 0 issues.
- 커밋: `290998a` `feat(parent): Provider에 ParentSyncService 콜백 연결 (fire-and-forget)`.
