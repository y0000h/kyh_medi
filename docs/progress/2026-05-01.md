## Task 0.7 — Supabase 프로젝트 + CLI + 마이그레이션 (진행 중)

**시각:** 15:24~ (진행 중)
**주체:** Claude 자동 + 사용자 콘솔 대기

### 자동 완료 (Claude)

- Node v24.14.0, npm 10.4.0 확인 → Supabase CLI 없음
- `npm install -g supabase` 시도 → Supabase가 글로벌 npm 설치 막음 (`Installing Supabase CLI as a global module is not supported`)
- `winget install Supabase.CLI` → "패키지를 찾을 수 없습니다"
- → **GitHub release에서 직접 binary 다운로드**:
  - URL: `https://github.com/supabase/cli/releases/download/v2.95.4/supabase_windows_amd64.tar.gz`
  - 다운로드 + 추출 → `~/bin/supabase.exe` (98MB)
- `~/.bashrc`에 `export PATH="$HOME/bin:$PATH"` 영구 추가 (이전 KUBECONFIG 설정 옆)
- 임시 PATH 적용 + `supabase --version` → **2.95.4** ✅
- `supabase init` → `supabase/config.toml` 등 생성됨
- `supabase migration new init` → `supabase/migrations/20260501061039_init.sql` (빈 파일) 생성
- 위 빈 파일에 v2.0 스키마 작성:
  - 테이블 6개: parent_devices, child_users, pairings, pairing_codes, medications, dose_events
  - 인덱스 3개
  - RLS 정책 (parent_devices/child_users 본인만, pairings 양쪽, medications/dose_events 부모+페어링자녀, pairing_codes 부모만)
  - RPC 2개: `create_pairing_code()`, `redeem_pairing_code(p_code, p_label)`

### 사용자 대기 중

다음 정보 알려주시면 진행:
1. **Supabase Project URL** (예: `https://abcd1234.supabase.co`)
2. **Project ref** (URL의 `abcd1234` 부분)
3. **anon public key** (긴 JWT, `eyJ...`로 시작)

- `supabase login` (사용자 브라우저 OAuth 1번)
